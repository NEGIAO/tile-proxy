地图瓦片直通代理 + 国内坐标纠偏

把高德 / 腾讯 / 天地图（GCJ-02）与百度（BD-09）瓦片，逐瓦片重采样成与 WGS84 标准 XYZ 对齐的 PNG，前端零改造即可叠加 GPS、OSM、Esri 等数据；也可由境外服务器代拉 Google / Carto 等瓦片并处理 CORS。本页同时是它的运行状态与配置控制台。

状态读取中…

GCJ-02 纠偏

高德电子/影像为火星坐标，按标准 XYZ 直贴会整城偏移。经 /proxy/gcj2wgs/ 输出后与 WGS 数据对齐。

/proxy/gcj2wgs/http://webrd01.is.autonavi.com/appmaptile?…&x={x}&y={y}&z={z}

百度 BD-09 纠偏

百度网格非标准 XYZ（原点居中、Y 向上）。bd2wgs 跨网格重采样，索引用标准 XYZ。

/proxy/bd2wgs/https://maponline0.bdimg.com/tile/?qt=vtile&x={x}&y={y}&z={z}…

境外源直通

浏览器直连 Google / Carto 等不稳定或无 CORS 时，由本服务代取并回源，补 UA / Referer。

/proxy/a.basemaps.cartocdn.com/rastertiles/voyager/{z}/{x}/{y}.png

路由一览

路径用途
/health探活
/proxy/{host+path}通用直通
/proxy/gcj2wgs/{url}GCJ 瓦片 → WGS84
/proxy/wgs2gcj/{url}WGS84 → GCJ 网格
/proxy/bd2wgs/{url}BD-09 → WGS84
/proxy/wgs2bd/{url}WGS84 → 百度网格
/admin/status · /admin/login · /admin/config本页用到的管理接口（写操作需登录令牌）

OpenLayers 接入（高德纠偏）

new ol.layer.Tile({ source: new ol.source.XYZ({ url: location.origin + "/proxy/gcj2wgs/" + "http://webrd01.is.autonavi.com/appmaptile?lang=zh_cn&size=1&scale=1&style=8&x={x}&y={y}&z={z}" }) });

之后 GPS 轨迹、GeoJSON、OSM 叠加层坐标保持 WGS84 原样即可。更多部署与原理见仓库 README / docs。

配置管理

首次使用：请先为这个实例设置管理密码（至少 8 位）。密码只存 PBKDF2 哈希，不会保存明文；设置完成后才能修改配置。

修改配置需要管理密码。密码只存 PBKDF2 哈希（SQLite），登录后换取 12 小时有效的令牌。
